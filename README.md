# 무한 서약

회귀형 2D 스토리 RPG — 웹 프로토타입 (Phaser 3 + TypeScript + Vite)

설계 배경과 전체 시스템 문서는 별도의 게임 디자인 노트(아티팩트)를 참고하세요.
이 저장소는 그중 **1단계 버티컬 슬라이스**를 검증하기 위한 최소 구현입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 안내되는 로컬 주소로 접속하면 됩니다.

## 지금 들어있는 것

- `src/systems/RegressionSystem.ts` — 세이브 포인트, 죽음 페널티, 달성 기록·파편·NPC 신뢰·스토리 플래그
- `src/systems/DialogueSystem.ts` — 선택지/자유 텍스트 대화 노드, 키워드 기반 자유 입력 판정
- `src/systems/EndingSystem.ts` — 신뢰도·스토리 플래그로 4개 엔딩 중 하나를 판정
- `src/data/regions.ts` — 지역 설정(배경·함정·분기점·NPC 배치). 침수 회랑 → 재의 시장 → 서리 관측소 순서로 연결
- `src/data/dialogues/*.ts` — NPC별 대화 트리 (이스라·리브 칸·헬가 도른)
- `src/scenes/RegionScene.ts` — 지역 설정을 읽어 실제로 그리는 재사용 가능한 필드 씬
- `src/scenes/DialogueScene.ts` — 대화 UI, 계통색 문장, 신뢰가 걸린 순간의 자유 텍스트 입력
- `src/scenes/EndingScene.ts` — 엔딩 화면, 처음부터 다시 시작 가능
- `src/scenes/StatusOverlayScene.ts` — 무한 서약 상태창 오버레이 UI

## 조작

방향키로 이동. 붉은 영역(함정)에 닿으면 죽음 페널티가 하나 누적되고 최근 분기점으로 되돌아갑니다.
초록 원(분기점)에 닿으면 세이브 포인트가 갱신되고, 오른쪽 가장자리의 "다음 지역" 구역으로 이동할 수 있습니다.
NPC(색이 있는 원)에 닿으면 대화가 시작되며, 특정 순간엔 직접 대사를 입력할 수 있습니다.
서리 관측소에서 헬가 도른과의 대화를 끝내면 지금까지의 신뢰도·선택에 따라 4개 엔딩 중 하나로 이어집니다.

## 전투

끝없는 계단의 "무너지는 계단참"에 닿으면 즉사 대신 전투가 시작됩니다. "기초 타격"은 언제나 쓸 수 있고,
"막바지 승부"는 체력이 30% 이하일 때만 쓸 수 있는 하이리스크 스킬입니다 (성공하면 크게 뒤집지만
실패하면 반동 피해). 여기서 죽으면 회귀 페널티가 붙지만, **다음 시도부터는 적의 다음 공격을 미리
알려주는 "죽음의 기억" 힌트가 뜹니다** — 정보 우위가 실제로 체감되는지 검증하기 위한 장치입니다
(로드맵 7.2 참고).
