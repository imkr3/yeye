# 무한 서약

회귀형 2D 스토리 RPG — 웹 프로토타입 (Phaser 3 + TypeScript + Vite)

설계 배경과 전체 시스템 문서는 별도의 게임 디자인 노트(아티팩트)를 참고하세요.
이 저장소는 그중 **1단계 버티컬 슬라이스**를 검증하기 위한 최소 구현입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 안내되는 로컬 주소로 접속하면 됩니다.

## 지금 들어있는 것

- `src/systems/RegressionSystem.ts` — 세이브 포인트, 죽음 페널티, 달성 기록·파편 지급 로직
- `src/scenes/FieldScene.ts` — 임시 지역(도형 기반). 함정에 닿으면 회귀, 분기점에 닿으면 세이브 포인트 갱신
- `src/scenes/StatusOverlayScene.ts` — 무한 서약 상태창 오버레이 UI

## 조작

방향키로 이동. 붉은 영역(함정)에 닿으면 죽음 페널티가 하나 누적되고 최근 분기점으로 되돌아갑니다.
초록 원(분기점)에 닿으면 세이브 포인트가 갱신되고 달성 기록이 하나 등록됩니다.
